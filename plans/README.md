## Findings considered and rejected

- **Admin commands unprotected** (scope `all_chat_administrators` looked display-only): wrong. `@grammyjs/commands` applies `.filter(isAdmin)` for that scope (`node_modules/@grammyjs/commands/out/command.js:327`).
- **Group commands run twice for admins** (registered in two scopes): no. The first matching branch handles it and the handler doesn't call `next()`.
- **Text injection in replies**: no `parse_mode` is used anywhere, so names are sent as plain text.
- **`pg-native` require in the bundle**: it is lazy and only runs on `pg.native` access. Plan 007 Step 2 verifies the bundle runs standalone.
- **Switch gif/sticker matching to `file_unique_id`**: the maintainer reports it did not match re-sent media in practice. The parser is kept and slimmed (005).
- **PostgreSQL → `node:sqlite`**: the maintainer chose to keep PostgreSQL.
- **🤡 reactions as votes**: reaction updates carry no message author. It would require storing message→author mappings, which contradicts the `/privacy` promise.
- **Jurisdiction / sanctions (hosting of the DB holding user ids, names, vote graph)**: the developer decided to skip ("open-source project, not a concern"). The code itself has no sanctioned-state touchpoints. `@fullstacksjs/oxlint-config` is dev-only and pinned, so it is low impact.
